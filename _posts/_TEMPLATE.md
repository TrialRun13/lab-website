# HOW TO ADD NEWS
# 1. Copy this file and rename it to YYYY-MM-DD-short-title.md  (e.g. 2026-10-04-thesis-defence.md)
#    Files that don't start with a date are ignored, which is why this template never shows up.
# 2. Edit the fields below and write the post in Markdown under the second ---
title: "Your headline here"
category: Publication   # Publication | Award | Lab life | Event | Talk | Funding
image: /assets/img/gallery/your-image.jpg   # optional; delete the line if none
---
Write one or two short paragraphs. Markdown works: **bold**, *italic*, [links](https://example.org), lists, images.
